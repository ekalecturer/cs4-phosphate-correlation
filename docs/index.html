The paper's own conclusion

"Correlations must be included in Monte Carlo Simulation otherwise the analysis leads to an underestimate of risk. It is relatively more important to investigate and allow correlations between the variables than to select the best fit distribution to represent the parameters."
A detail worth knowing: two of the seven "uncertain" parameters in scenario 4 — income tax rate and mill recovery — are reported with 0% standard deviation in the paper's own Table 6. A variable that does not vary is not really uncertain. This tool exposes the five parameters that actually had nonzero variance: price, operating cost, grade, interest rate, inflation.

What the notebook demonstrates

Using the paper's real distributions and real correlation matrix (price-inflation correlation: 0.94), the notebook runs the model twice — once honoring the correlation, once with it destroyed — to isolate what correlation modeling actually buys you. It does not reproduce the paper's exact cash-flow mechanics (depreciation and depletion schedules aren't fully disclosed), and says so directly in the notebook itself.
